# Homebrew Tap

Add this tap:
```console
$ brew tap jacquerie/tap
```

Then trust it:
```console
$ brew trust jacquerie/tap
```

## Casks

### DS4 Control

Install:
```console
$ brew install --cask jacquerie/tap/ds4-control
```

### Nativ

Install:
```console
$ brew install --cask jacquerie/tap/nativ
```
